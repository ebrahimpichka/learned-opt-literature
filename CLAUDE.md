# Learned-optimizer literature vault

Bibliography on learned optimizers and their connection to graph metanetworks / weight-space learning.

- **Read `discovery/LOG.md` first**: what was done, when, which date windows were searched, and why
  some decisions were made. Add a short dated entry for any non-trivial manual work.
- Source of truth: `papers.bib`. `README.md` (by topic) and `BY_YEAR.md` (by year) are generated by
  `python manage_papers.py readme`; never edit them by hand.
- Use `.venv/Scripts/python.exe manage_papers.py <cmd>`; queries, seeds, topics and scoring live in
  `discovery.toml`. Not a git repo: back up `papers.bib` before bulk edits.
- Topics = bib `keywords`, primary first. A weight-space paper connected to learned optimizers carries
  both `metanetworks` and `learned-optimizers` (check with `manage_papers.py lo-evidence`).
- Semantic Scholar is often rate-limited without `S2_API_KEY`; use `add --skip-s2` and the
  arXiv/OpenAlex discovery sources.
